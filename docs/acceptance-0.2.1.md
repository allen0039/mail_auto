# 0.2.1 原邮箱分类与可视化 MCP 验收

日期：2026-10-22。构建、测试、浏览器与运行验证均在独立 Linux 环境进行，浏览器使用虚构数据。不连接 AI API。

## 本次修正

- 用户确认按原邮箱文件夹分类。主界面与 MCP 移除本地标签入口，目标来自原邮箱真实文件夹；支持 CREATE + LIST 确认后的原邮箱文件夹创建。
- 归档、回收站独立可选；支持只有 UIDPLUS、没有 MOVE 的受控兼容移动。
- MCP 页面保存域名/开关，立即生效、重启保留；提供 HTTPS 检测、Codex 命令/TOML、ChatGPT 连接地址。无域名时留空关闭。
- schema 4→5 新增 MCP 设置，不重置账号、文件夹映射、写入开关或旧邮件引用。

## 隔离验证

- `go test ./... -count=1 -timeout=120s`、`go vet ./...`：通过。
- 原生 MOVE/COPYUID 保留；UIDPLUS-only 协议测试覆盖成功、COPY 断线、无映射、映射保存失败、目标不可见、STORE 断线、UID EXPUNGE 断线与假成功但源 UID 仍存在。所有早期失败均不删除源；仅 UID EXPUNGE 指定源 UID，没有全局 EXPUNGE/CLOSE 或重复 COPY/MOVE。
- 原邮箱创建成功/未出现在 LIST/Noselect/断线；失败不发布本地分类，权限与写入开关即时生效。
- 未配置归档仍可分类、回收站；离线也能关闭写入；拒绝创建本地标签计划。
- 冻结位置、并发幂等、撤销冲突、未知结果核验、恢复原目录和中断重启继续受既有测试保护。
- MCP API 会话/CSRF、非法 HTTP/路径地址、空地址关闭、热启停、并发版本冲突、数据库优先于旧 CLI、域名更换撤销令牌、受信任 TLS 检测/错误代理、反代 Secure Cookie 与并发读写验证。
- OAuth/SDK 测试使用数据库保存的 HTTPS 地址，覆盖 PKCE、授权码重放、刷新轮换、撤销、账号隔离、只读授权拒绝创建原邮箱目录。
- schema 2→5 与 4→5 迁移、账号密文、映射版本、稳定 ref、历史元数据保留和完整性检查。

Playwright 使用独立 Go 模拟提供商，不允许真实 IMAP 连接。浏览器创建文件夹后，直接读取模拟提供商状态验证目录存在；3 封邮件分类到「账单」后检查源为空/目标 3 封，移入「已删除」后再次核对，恢复后确认返回「账单」。同时验证写入关闭时无法创建文件夹、无本地标签入口、UIDPLUS-only 提示、无归档映射可整理、MCP 保存/复制内容/页面刷新/进程重启保留、管理员会话保留。桌面与 390px 手机无页面异常、无横向溢出。截图与原始验收日志仅本地保留，不随源码发布。

`go test -race ./... -count=1 -timeout=300s` 全包通过。最终镜像验证非 root、只读根目录、健康、首次设置闸门、内置 0.2.1 UI、MCP 配置持久化、容器重建保留会话/密钥、schema 5 完整性与默认 MCP 关闭。

## 发布与回退

升级前创建一致性 SQLite 快照，并单独备份主密钥、Compose 文件与旧镜像信息；目录 0700、文件 0600。schema 4→5 不提供 down；回退须先停止服务，恢复配套数据库、密钥及旧镜像，不能让旧程序直接打开新库。

部署验证确认原有数据、加密凭据、会话与主密钥保持，schema 5 完整性检查通过，健康检查正常。MCP 默认关闭，未使用真实邮件进行写入测试。生产地址、账号统计、备份路径和实例标识不公开。

## 保留验证边界

真实邮箱未执行创建文件夹、移动、归档或回收站试写，三家邮箱的实际写权限与手机同步尚未验收。公网 HTTPS、实际 Codex / ChatGPT OAuth 连接需用户后续完成反代后验收。能力探测只读取声明和目录，不能替代真实写权限验证。兼容移动中断可能留下两处副本或 Deleted 源项，不自动重试，也不承诺服务端事务原子性。

隔离 QA 目录、模拟数据库/密钥、浏览器依赖和专用 Go 缓存卷已清理；保留升级备份、回退镜像、验收日志与虚构数据截图。清理后正式实例仍 healthy。
