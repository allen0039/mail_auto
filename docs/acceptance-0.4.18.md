## 二、剩余竞态与技术限制

1. **IMAP 协议固有无原子验证删除**：CONDSTORE 的 `UNCHANGEDSINCE` 无法跨 STORE 与 UID EXPUNGE 命令保护，且非所有服务商均支持。实现保证：清理前最后一次状态检查在同一会话中紧邻 UID EXPUNGE 发出；若检测到状态受保护则立即撤销删除并终止。最后读取至 EXPUNGE 之间的毫秒级外部并发修改无法由客户端完全排除。
2. **撤回 `\Deleted` 异常断线**：若第二次保护检查失败后撤回 `\Deleted` 的命令本身断线，源邮件会带 `\Deleted` 标记保留在原目录，操作保持待核验，下次核验重新评估。
3. **无服务器目标 UID 映射**：未拿到 COPYUID 的操作绝不自动补完，保持待核验由人工核对，不凭元数据或主题猜测。
4. **附加标记不自动补写**：移动恢复不补发标记写入，显式标记 `flags_not_applied` 并产生告警计数，提示用户按需手动处理。
5. **R5 快捷关闭入口与 R6 规则范围微调**：按规划不纳入本版。
