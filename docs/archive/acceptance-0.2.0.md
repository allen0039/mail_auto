# 0.2.0 验收记录

日期：2026-10-22。构建、运行和测试在独立 Linux 环境进行，浏览器使用虚构数据。不接入 AI API。

## 实现与隔离验证

| 范围 | 结果 |
| --- | --- |
| schema 2 → 4 | 模拟旧库保留账号范围、加密凭据、消息引用；独立身份表、标签关联、删除/重新绑定及账号级联、完整性检查通过 |
| 本地标签 | 创建、添加/移除、筛选、定义删除和校验；Web 与 MCP 共用服务 |
| 操作计划/任务 | 500 封上限、10 分钟有效期、固定引用、逐项状态、幂等、取消剩余项、位置及配置校验 |
| 移动/恢复 | 虚构适配器验证归档、回收站、恢复、稳定引用和标签跨移动保留；同步刷新不会重置已确认绑定 |
| 未知结果 | 保存 COPYUID 后断线、核验、重复核验不重发 MOVE；服务重启不重新发送中断的移动 |
| 撤销 | 生成补偿计划；后续标签变化拒绝覆盖，位置变化跳过 |
| IMAP 协议 | 模拟连接验证直接 UID MOVE、单一 COPYUID、写后源/目标检查、断线保留映射；无 STORE/COPY/全局 EXPUNGE 降级 |
| MCP | 官方 Go SDK HTTP 客户端初始化、工具发现/调用、结构化结果、跨账号拒绝、只读授权拒绝写入、撤销后 HTTP 拒绝 |
| OAuth | HTTPS 元数据、DCR、账号/动作确认、会话/CSRF、S256 PKCE、错误资源拒绝、单次授权码、刷新轮换、撤销后禁止刷新 |
| 默认配置 | 无域名且 MCP 关闭可启动；缺少 HTTPS 时拒绝启用 MCP；远端写入各账号默认关闭 |
| 自动检查 | 全量 `go test ./...`、`go vet ./...`；mail/store/admin/mcpserver/imap 的 race 检查通过 |
| 漏洞扫描 | 当前调用路径 0、当前导入包 0；模块层 1 个未调用问题，不等于模块不存在历史风险 |
| 浏览器 | Linux Python Playwright：初始化、标签创建、3 封预览/执行/结果/标签筛选、未配置写入拦截、MCP 关闭提示，桌面和 390px 手机无横向溢出，页面异常 0 |

浏览器测试使用临时模拟提供商，不连接真实邮箱。私有验收脚本、运行日志和截图不随源码发布。

复查中发现并修复：计划 JSON 遗失 IMAP 标识、移动结果发布 INSERT 列数错误、标签补偿覆盖后续修改、同键并发提交冲突、恢复历史未匹配当前目标 UID、标签筛选控件未插入 HTML。修复后补充或重跑相关验证。

| --- | --- | --- |
| 网易现有账号 | 0.1.0 已验证全目录与自动增量；发布后继续检查 | 未用真实邮件验证，默认关闭 |

初版不实现无原生 MOVE 的降级。能力检测读取服务器声明和 LIST 目录，实际目标写权限仍以执行时服务器响应为准。没有设置反代或域名，MCP 不公开。未自动配置真实目录映射，未改动真实远端邮件，不将隔离协议测试当作真实服务商兼容性验收。

## 发布与回退

发布前备份一致性数据库与独立主密钥，并保留旧镜像。schema 已升至 4，旧 0.1.0 程序会拒绝打开新库。回退必须先停止服务，恢复升级前数据库及配套主密钥，再使用旧镜像。恢复快照会放弃升级后变更。

隔离验证覆盖非 root、只读根文件系统、健康状态、静态资源、匿名访问边界与容器重建后的卷持久化。正式服务未用真实邮件执行移动或删除；生产地址、备份路径、实例标识和账号统计不公开。
