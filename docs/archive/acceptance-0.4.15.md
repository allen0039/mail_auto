# 0.4.15 验证范围

日期：2026-11-12。本次将 0.4.11–0.4.14 的工作区改动纳入正式源码发布，统一发布版本为 0.4.15；数据库 schema 不变。

- 自动化不再限制每日领取和入队数量；保留每批数量、未读/星标保护、授权及任务期限。
- 固定规则批次暂停后台同步连接，并复用已登录 IMAP 会话完成最新状态核验和移动。
- 中断操作由后台以 30 秒退避自动核验，仅处理最近 24 小时的操作；已发出的 MOVE 不会自动重放。
- 全量竞态测试、静态检查、漏洞扫描、前端语法和 Compose 校验通过。

测试使用模拟 IMAP、SQLite 和 HTTP 数据；不等同于所有真实邮箱服务商兼容性验证。此前恢复边界详见 [审计记录](audit-2026-11-12.md)。
