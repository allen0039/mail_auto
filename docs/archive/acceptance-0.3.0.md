# 0.3.0 验收记录

日期：2026-10-22。构建、测试和浏览器运行于 独立 Linux 环境；Mac 仅编辑源码、文档和查看截图。没有使用真实邮件试写，没有创建真实外部定时任务。

## 本次交付

- 原邮箱文件夹规则：嵌套全部/任一/排除、优先级、版本、启停、复制、模板和模拟命中。
- 服务器收信日期、星标、标记完整性和状态变化时间，schema 5 → 6 保留旧引用及加密凭据，后台同步补齐。
- 管理员限定源目录、目标、动作、正文访问、保护联系人、历史起点、稳定等待、额度和到期日；默认关闭、只观察。
- MCP 外部批次领取、跨客户端租约、签名、幂等提交、冻结计划、每日限额、执行前权限/规则/原邮箱最新状态复核、取消及运行记录。
- 页面生成外部任务说明，保留既有可视化 MCP 地址/开关/检测/OAuth 配置。服务端无模型调用、无整理调度器。

## 验证

- Go 完整测试、vet、全包 race 检测全部通过。覆盖 SDK HTTP 工具调用、嵌套规则 schema、权限/正文/原始 plan 绕过、规则和策略版本冲突、并发领取、每日额度、过期、取消、远端星标变化、跨日旧队列拒绝写入。
- 真实 IMAP 协议夹具验证只读 EXAMINE + 元数据 FETCH、收信日期/星标、UIDVALIDITY 变化拦截，不读正文、不发送 STORE/EXPUNGE。
- schema 5 原始列形状迁移验证稳定引用、凭据不变，新字段未知、不自动创建自动化授权。
- govulncheck：调用路径和导入包受影响漏洞均为 0，依赖模块级有 1 个未调用问题；源码及正式 Compose 校验通过。
- Python Playwright 桌面和 390px 手机验证实际保存、嵌套规则重开、版本历史、试运行、策略、任务说明、批次记录、暂停/复制及特殊字符转义。页面异常 0，无横向溢出。
- 在隔离模拟提供商上，经真实 MCP HTTP 完成观察和执行：初始收件箱 3 封；观察没有移动；执行两份计划后，分类目录 2 封、收件箱 1 封未读。直接查询提供商状态核对，未只检查本地索引。

第一次 SDK 测试发现递归类型不能自动生成 schema，改为最大三层的显式有限输入格式。第一次 race 的业务包均通过，但测试夹具恰在编译期间被修改而失败，最终重新冻结源码补跑。浏览器首次脚本将 textarea 值当文本断言，调整测试后通过，无对应产品错误。

## 边界

QQ/网易/iCloud 原生标签为未验证，未开放标签读写；不导入桌面客户端私有标签或筛选定义。分类使用原邮箱文件夹。

真实 Codex/ChatGPT 定时任务、OAuth 长期续期和无人值守写入确认，以及各真实服务商写入仍需专用测试邮件验收。本次没有将任务说明误报为已创建的外部任务。IMAP 复核和移动存在两条命令之间的竞态，未声称原子事务。

## 发布记录

本版本验证使用独立 Linux 测试环境和隔离模拟提供商，未发布生产地址、备份路径、实例标识或账号统计。容器通过非 root、只读文件系统、健康检查和重启后的虚构数据持久化验证。

升级和回退需要同时保留数据库快照、匹配主密钥、Compose 配置与旧镜像；不能只替换旧二进制打开新 schema。正式发布使用 `allen0039/mail-auto` 镜像，具体标签和摘要以仓库发布记录为准。
