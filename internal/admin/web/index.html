备份与账号恢复

一致性备份：

docker compose exec app mail-auto backup /var/lib/mail-auto/data/backup.db

请另行备份独立密钥卷中的 master.key。恢复账号：

docker compose exec app mail-auto bootstrap recover

恢复会撤销全部登录会话。之后执行 bootstrap show，重新完成首次设置。详细步骤见项目 docs/operations.md。
